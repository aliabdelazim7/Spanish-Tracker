# Ruta Español (Spanish Tracker) 🇪🇸🇪🇬

> منصة تعليمية احترافية لإتقان اللغة الإسبانية القشتالية (Castellano de España) للمتعلمين الناطقين بالعربية، مع شروحات مقربة للأذهان باللهجة المصرية والفصحى ومحاكاة حية للحياة اليومية في إسبانيا.

---

## 🌟 الميزات الرئيسية (Core Features)

1. **المسار التعليمي المعتمد (CEFR Curriculum)**:
   - مستويات واضحة من **A1 إلى C2** مع وحدات ودروس تفاعلية محددة الأهداف.
2. **محرك الدروس المتعدد (Interactive Lesson Engine)**:
   - يدعم: اختيار من متعدد، ترجمة، أكمل الفراغ، ترتيب الكلمات، وتوصيل أزواج الكلمات.
3. **اختبار تحديد المستوى التكيفي (Adaptive Placement Engine)**:
   - يقيس المفردات، القواعد، وفهم المقروء مع تقرير تشخيصي فوري يوصي بالوحدة المناسبة للبدء.
4. **القصص التفاعلية في شوارع مدريد (Interactive Stories Mode)**:
   - قراءة جملة بجملة لحوارات واقعية (المطار، المترو، المقاهي) مع ترجمة فورية عند النقر على أي كلمة.
5. **نظام التكرار المتباعد للمفردات (Spaced Repetition System - SM-2)**:
   - جدولة علمية للكلمات لمراجعتها قبل نسيانها مباشرة ونقلها للذاكرة الدائمة.
6. **معلم الذكاء الاصطناعي واستوديو النطق (AI Tutor & Speaking Studio)**:
   - تدريب صوتي مع مقارنة مخارج الحروف، شرح القواعد بالعامية المصرية، ومصحح للتراكيب اللغوية.
7. **مذكرات التعلم واليوميات الإسبانية (Spanish Journal)**:
   - مساحة مخصصة للكتابة الحرة والتدوين مع اقتراحات لموضوعات تناسب مستوى المتعلم (A1-C2).
   - محرك تحليل بالذكاء الاصطناعي يقيم القواعد، المفردات، وسلاسة الأسلوب، مع مقارنة بصرية بين النص الأصلي والنص المقترح (مع الحفاظ الصارم على النص الأصلي للمتعلم دون تعديل مباشر).
8. **ملف الأخطاء الشخصي وتمارين التقوية الموجهة (Learner Error Profile & My Mistakes)**:
   - يتتبع أخطاء المتعلم المتكررة في الكتابة والدروس (مثل الفرق بين `ser` و `estar`، وتصريفات الأفعال).
   - يقدم توصيات تعليمية شارحة لسبب التوصية ("لاحظنا تكرار هذا الخطأ في مذكراتك...")، مع زر لبدء كويز تدريبي فوري لتعزيز الإتقان وكسب نقاط XP.
9. **الدعم ثنائي اللغة والواجهة المرنة (Bilingual Arabic & English UI with RTL/LTR)**:
   - دعم كامل للغتين العربية (افتراضياً مع اتجاه RTL) والإنجليزية (LTR)، مع تبديل فوري وحفظ للتفضيلات.
10. **النطق الصوتي الإسباني القشتالي الطبيعي (Castilian Audio & Speaking Studio)**:
    - نطق صوتي فوري بنقرة واحدة لجميع الكلمات والمفردات وجمل القصص بلكنة إسبانية قشتالية سليمة (`es-ES`).
    - استوديو نطق تفاعلي يقارن نطق المتعلم بالصوت المستهدف مع تقييم دقة النطق وشرح الملاحظات باللهجة المصرية.
11. **واجهة متوافقة تماماً مع الموبايل والتابلت (Mobile-First Responsive UX)**:
    - شريط تنقل سفلي ثابت للشاشات الصغيرة، أزرار لمس مريحة، وقوائم مخصصة لتجربة استخدام فائقة السلاسة.
12. **التحفيز والألعاب التعليمية (Gamification & Streaks)**:
    - عداد سلسلة الأيام المتتالية، نقاط الخبرة (XP) مع ضمانات منع تكرار المكافآت (Idempotency)، وأوسمة الإنجاز.

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, TanStack Query, React Hook Form, Zod, Lucide React, Canvas Confetti.
- **Backend**: PHP 8.4+, Laravel 12, Laravel Sanctum, Form Requests, Policies, Database Transactions.
- **Database**: PostgreSQL (Supabase) للإنتاج مع دعم SQLite للتطوير المحلي والاختبارات السريعة.
- **Deployment**: Vercel (Frontend SPA) + PHP Host / VPS (Laravel Backend).

## 🚀 البدء السريع والتشغيل المحلي (Local Quickstart)

### 1. المتطلبات الأساسية
- **PHP** (8.2 أو أحدث) مع امتدادات `pdo_sqlite` أو `pdo_pgsql`
- **Composer** (2.x)
- **Node.js** (v18 أو أحدث) و **npm**

### 2. تثبيت الحزم وإعداد البيئة

#### تشغيل الباك إند (Laravel API):
```bash
cd services/api
# نسخ ملف الإعدادات
cp .env.example .env
# توليد المفتاح السري
php artisan key:generate
# تشغيل الهجرات وزرع البيانات التعليمية الأولية
php artisan migrate --seed
# تشغيل خادم التطوير (على المنفذ 8000)
php artisan serve --port=8000
```

#### تشغيل الواجهة الأمامية (React Vite):
```bash
cd apps/web
# تثبيت الحزم
npm install
# تشغيل خادم التطوير المحلي
npm run dev
```

افتح المتصفح على: `http://localhost:5173`

## 📋 تشغيل الاختبارات الآلية (Automated Tests)

### اختبارات الباك إند (PHPUnit):
